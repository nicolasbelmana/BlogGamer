BlogGamer - Proyecto para CoderHouse
¡Bienvenido/a! Este repositorio contiene el desarrollo del proyecto web para el curso de CoderHouse, dividido en dos etapas de entrega.

📌 Etapa 1: PreEntrega-1-Belmaña
Primer prototipo desarrollado en wireframe.

Sitio web construido únicamente con HTML y CSS básico.

Se definió la estructura principal del sitio, sus secciones y componentes.

📌 Etapa 2: Entrega final
Implementación de Flexbox y CSS Grid.

Separación de estilos en dos hojas CSS:

base.css: estilos generales y estructura.

advanced.css: estilos avanzados, efectos, media queries, animaciones.

Proyecto versionado con Git y cargado en un repositorio público en GitHub.

Código optimizado para facilitar el mantenimiento y la lectura.

💻 Tecnologías utilizadas
HTML5

CSS3

Flexbox y Grid

Git & GitHub

🚀 Objetivo
El propósito del proyecto es aplicar los conocimientos adquiridos durante el curso, desarrollando un sitio web completo, ordenado y escalable, simulando un entorno de trabajo profesional.
